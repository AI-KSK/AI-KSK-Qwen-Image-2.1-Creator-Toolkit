# Depth Control 三维横评：方法、轴和可视化

## 实验研究问题

在 **同一张图、同一张 Depth 图、同一提示词、同一模型、同一 Seed 和同一采样参数**下，比较三类 ControlNet 参数对几何结构、人物姿态、透视和视觉自由度的影响。

## 变量与矩阵

| 变量 | 定义 | 值 |
| --- | --- | --- |
| X 轴 / Weight | 控制强度（Union `strength`） | 0.20, 0.40, 0.60, 0.80, 1.00 |
| Y 轴 / End | 控制作用结束的归一化去噪进度 | 0.60, 0.70, 0.80, 0.90, 1.00 |
| Z 轴 / Start | 控制作用开始的归一化去噪进度 | 0.00, 0.25, 0.50 |

共 **3 × 5 × 5 = 75 个不同参数组合**，额外 1 张 **不接 Depth Union** 的 Baseline。每层有一个 5×5 PreviewImage 矩阵，节点名称例如 `S0.25_E0.80_W0.60｜Preview 43/75`，精确列表在 [`data/depth75_matrix.csv`](../data/depth75_matrix.csv)。

`Start` 与 `End` 是**去噪进度比例**，不是视频时间、不是物理秒数。只有 `start_percent <= end_percent` 的组合才有意义；此实验全部有效。

## 固定采样参数

- Model：Qwen Image 2.1 Base（参见安装文档的模型兼容说明）
- Union ControlNet：Qwen-Image-2.1-Fun-Controlnet-Union
- Sampler：`euler`
- Scheduler：`simple`
- Steps：`25`
- CFG：`3.5`
- Denoise：`1.0`
- Seed：`9527` + `fixed`
- 提示词与负向提示词：各组相同
- 控制图：同一个 Depth Anything V2 的输出（或手动上传同一张深度图）

**这不是官方 Turbo 8 步实验**，因此这里的 `Euler + simple` 是原模型的基准设置，不应混淆到 8 步 Turbo 自定义 Sigmas。若未来增加 Turbo 实验，应该独立实验，并先依该 Turbo 实现要求重新核对 Sigmas。

## 教学时怎么展示

1. 放出原图与 Depth 灰度控制图，解释 Depth 保留几何远近关系而不是原画风。
2. 放出 Baseline，无 CN 看模型自由生成结构。
3. 在 Start=0 的第一层，同一行**从左到右**看权重 0.2 → 1.0。
4. 在同一列**从上到下**看 End=0.6 → 1.0。
5. 跨 Start=0,0.25,0.5 三层，用完全相同 Weight 和 End 的对应格比较“早介入 / 晚介入”的效果。
6. 用原图角色头部/兜帽/肩膀/膝盖的结构关系作为观察点，记录“几何像不像”和“画风保不保留”两个独立分数。

## 推荐评估维度

| 项目 | 主观评分建议 | 注意 |
| --- | --- | --- |
| 透视与空间层级 | 1–5 | 前景膝盖、躯干、头部远近关系 |
| 轮廓 / 姿态跟随 | 1–5 | 主体与 Depth 轮廓是否接近 |
| 身份 / 造型一致性 | 1–5 | 纯 Depth 无法保证人物身份，单独报告 |
| 画风一致性 | 1–5 | 厚涂、色块、边缘笔触是否改变 |
| 解剖结构完整性 | 1–5 | 手/膝/肩等位置是否畸形 |
| 风格自由度 | 1–5 | 不把“变化少”误认为质量必然最好 |
| 时间/显存 | 实测 | 不预填主观估计，不捏造数据 |

## 运行风险和限制

- 75 路并行排布 ≠ GPU 75 路同时跑；实际排队和执行顺序由 ComfyUI 决定。
- 一次全运行可能很慢、耗尽资源或遇到节点缓存/内存问题，建议分层分批。
- 5 格试验版把其余 70 格采样及相关节点设为 mode=4（Bypass），不同 ComfyUI 扩展对 Bypass 下游行为可能有差异。若被禁用分支仍报类型错误，可在 UI 中选择只运行已启用输出，或暂时手动解除 / 禁用相应下游。
- 没有 GPU 实测，不宣称出现了任何具体效果结论。权重和控制持续时间影响的方向需要凭实际图像证据判断。
