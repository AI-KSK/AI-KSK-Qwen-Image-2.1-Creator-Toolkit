# FAQ

**Q：Skill 安装要下载 ZIP 吗？**
不需要。安装源就是仓库里的 `skills/qwen-image-2-1-creator/` 目录，把它复制到 Codex 的 skills 目录即可，详见 [README 安装方法](../README.md#3-安装方法)。

**Q：安装 Skill 需要 GPU 吗？**
不需要。安装、阅读文档、校验示例任务和运行单元测试只需要 Python 3.10+。真实出图才需要 ComfyUI / GPU 或云端平台。

**Q：仓库里为什么没有生成好的图片或测试样片？**
因为本仓库的定位是 Skill 与配套工具，不含模型权重、不含他人版权素材，也不宣称未经实测的出图效果。

**Q：官方说支持 10 张参考图，为什么我的工作流只能接 2 张？**
官方 1–10 张是模型能力上限，实际可用张数取决于你的 ComfyUI 工作流真实暴露的输入端口数量。增加端口需要改造节点连线并另行测试。

**Q：可以把 `control_image` 当参考图来"复制"人物吗？**
不可以。`control_image` 只提供结构条件（姿态、轮廓、深度、建筑线条），身份、服装与画风应由 `reference_image` 和提示词约束。

**Q：Skill 会自己下载模型或帮我出图吗？**
不会。内置 Python 工具只做输入规范检查、指定节点提示词写入、工作流 diff 审计和视频交接单生成。模型下载、节点部署与推理都必须在你的真实环境中完成。

**Q：视频路由能直接生成视频吗？**
不能。Qwen Image 2.1 是图像生成/编辑模型。`video_*` 路由只产出交给 Wan / H3 等**外部**视频模型执行的交接单。

**Q：能商业使用 ControlNet 权重吗？**
不能因为代码上传 GitHub 就推断权重允许商用。Union 权重受上游研究/非商业许可限制，商业使用需另行获得合法授权，详见 [授权与署名说明](LICENSES_AND_ATTRIBUTION_CN.md)。

**Q：Skill 的能力有没有经过真实 GPU 验证？**
仓库内不包含 GPU 实测结果。任何未经真实运行验证的内容一律视为 `runtime_pending`；如需宣称"已验证"，请自行提供环境版本、日志与结果。
