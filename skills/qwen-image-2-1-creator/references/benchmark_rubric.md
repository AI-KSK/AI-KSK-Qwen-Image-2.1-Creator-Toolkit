# 图像/视频横评质量准则

每个测试样本保存 `task_id`、输入图片哈希、提示词哈希、模型版本/LoRA 文件及强度、Seed、分辨率、Steps、CFG、Sampler、Scheduler/sigma、GPU/环境、预热情况、耗时（秒）、峰值 VRAM（GB）和输出路径。

打分维度（0~5，各项分别给分，不要主观综合分代替原始数据）：
- 语义：正确主体、数量、动作、关系；
- 结构：手/脸/身体/几何、物体拓扑；
- 视觉：材质、光影、边缘、微细节、过锐化/塑料感；
- 文本：目标中英文逐字核对，不是“看起来差不多”；
- 一致性：脸/衣服/产品商标、非目标区域保留程度；
- 透明：PNG alpha 信息、背景无残留色边；
- 视频扩展：身份漂移、动作物理、相机连续性、音画对应（视频模型额外评分）。

同种变量对照才允许归因。`Base 25步 CFG 3.5` vs `Turbo LoRA 8步 CFG1.0` 是端到端不同方案的性能/画质比较，不能据此判断“仅 LoRA 造成了什么差异”。
